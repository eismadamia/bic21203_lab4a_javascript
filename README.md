## About
This project contains three JavaScript activities covering button events,
input validation, loops and DOM manipulation.

## How to Run
Open the `index.html` file in each question folder using a web browser.

- **Q1:** Click “Change Message” to change the paragraph text.
- **Q2:** Enter a value and click “Check” to see whether it is below, equal to or above 10.
- **Q3:** Click “Generate” to display the numbers 1 to 5.
